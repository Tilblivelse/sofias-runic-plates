Each photo was matched to the catalogue either by runic signum, as recorded by the Swedish History Museum, or by find place and year, as stated in the Commons caption. Museum records sometimes classify a plate's metal differently from the book (the Järfälla plate, for example, is copper in the catalogue and a copper alloy in the museum record), so check the book where it matters.

## Source and scope

Pereswetoff-Morath, Sofia. *Viking-Age Runic Plates: Readings and Interpretations*. Translated by Mindy MacLeod. Runrön 21 / Acta Academiae Regiae Gustavi Adolphi 155. Uppsala, 2019.

This is an independent, unofficial catalogue of facts about the plates. It contains no runic transcriptions, readings, or text, photographs or drawings from the book, and it is not affiliated with the author, publisher, or Uppsala University. For the inscriptions themselves, please consult the book and the Runic-text Database.
